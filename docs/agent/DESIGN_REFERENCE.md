# Design Reference

One-time summary of the 32 supplied desktop screenshots. Re-open the source ZIP only if a later design phase finds this map stale.

## Global visual language

- Premium editorial real-estate presentation: warm off-white canvas, deep ink evidence panels, restrained bronze/brown actions and fine rules.
- Large Dubai/property photography carries hierarchy; controls stay compact and quiet.
- High-character display typography for narrative headings; plain, dense UI type for facts, filters and tables.
- Evidence labels, source dates, modeled/illustrative badges and missing-data states are visible rather than hidden.
- Desktop layouts use disciplined whitespace, narrow content rails and sticky decision panels. Mobile/RTL must be intentionally recomposed in later phases.

## Route/component intent

| Surface | Reference intent |
|---|---|
| Home hero | Full-width Dubai dusk image, evidence-first statement, natural-language search and compact community-map preview |
| Market Pulse | Six restrained KPI cards with period/source context and methodology access |
| Opportunity Radar | Explainable lens chips and image-led listing cards |
| Investment Atlas | Dark spatial-intelligence section, layer list and schematic map |
| Property grids | Strong image ratio, minimal chrome, factual price/location/spec rows and evidence badges |
| Recently viewed / launches | Horizontal inventory rail; launch cards include developer, handover and construction progress |
| Community Intelligence | Curated area cards backed by live metrics and inventory |
| AI Advisor preview | Structured comparison table, trade-offs and sources, clearly labeled demonstration/live state |
| Scenario Lab | Few inputs, deterministic outputs, assumptions and matching-property route |
| Evidence layer | Dark module with source/methodology access and measured claims |
| Advisors / international / trust | Real people and direct channels; sourced buyer guides; countable trust signals |
| Search | Editorial header, query/filter hierarchy, tabs/chips, dense image-led results |
| Property detail | Gallery hero; persistent inquiry/price panel; facts, narrative, amenities, payment plan, floor plan, history, market context, costs and location |
| Map/list | Large interactive map with explicit layers and branded markers synchronized to a scrollable result rail |
| Market Intelligence | Evidence-forward dashboard, explorers, two-to-four-community comparison, charts and heatmap/table |
| Calculators | Tool hub plus sober scenario forms, deterministic results, assumptions and charts |
| Advisor directory | Card grid with headshots, roles, direct call/WhatsApp and profile links |
| AI Advisor full | Wide conversation workspace, suggested prompts, guardrails and human handoff panel |

## Guardrails for later phases

- Preserve the existing brand tokens and evidence-first behavior; do not replace with a generic admin/SaaS kit.
- Restore this visual quality only after the canonical data and worker path are real.
- Never hard-code inventory or market facts merely to reproduce a screenshot.
